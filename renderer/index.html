How to use
  1. Accept missions in-game — the Session timer starts automatically from the log.
  2. Enable Show timer on overlay to see elapsed time on the in-game bar.
  3. Set Overlay mode to Click to scan, then click the blue circle next to a resource to record 1 shared scan.
  4. Pick a Deposit sound and volume; Test previews the alert.
  5. Record Scan applies shared progress across active missions.
